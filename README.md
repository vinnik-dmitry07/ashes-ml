# AHSL 1.0

Итоговая формальная спецификация проверяемого исследования и адаптации.

Читайте `SPEC.md`: новый дизайн, точная семантика F1 и неизменённая спецификация R06 в приложении. `DESIGN.md` содержит новый текст без приложения. `verification.json` фиксирует реально выполненные проверки.

## Запуск

Python 3.12+, стандартная библиотека. После распаковки перейдите в каталог `ahsl-1.0` и выполните:

```bash
python verify.py
```

Проверка локальна, не обращается к LLM, не обучает модель и не выполняет действий во внешних приложениях. Она проверяет lock, запускает унаследованные тесты исполнения, новые тесты композиции и конечный перебор графов. Также формируется пример `examples/conditional-plan.json`.

## Покрытие

| Часть | Реализовано |
|---|---|
| `runtime_0_6/` | Прежний детерминированный протокол исполнения и статистического допуска, сохранён без изменения |
| `prospection.py` | Конечная булева логика, проверяемые условные схемы, AND/OR-замыкание, ссылки на версии и бюджет проверки |
| `exhaustive.py` | 4096 сочетаний графа и исходных сертификатов на трёх узлах; 48 булевых проверок |
| `tests/` | Контрпримеры: циклы, несовместимые предпосылки, подмена контекста, отчёт вместо доказательства, повторные события |

Профили R06 и F1 независимы. F1 не добавляет proof-gate к выпуску R06. Контракт интеграции X1 описан в спецификации; его физический адаптер не реализован.

`VERIFIED` в F1 означает истинность формулы в конечной заявленной области. Он не означает, что произвольная программа безопасна, модель мира истинна или обученная LLM надёжна.

Тесты и конечный перебор не являются машинным доказательством общей корректности. Пакет не содержит результатов реального агентного бенчмарка.
