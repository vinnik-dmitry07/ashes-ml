# Изменения AHSL 1.4

Дата: 2026-09-10. База: присланный исполняемый AHSL 1.3.

| Изменение | Статус и результат |
|---|---|
| Обход AST в trim_alias | Исправлен дефект: литералы остаются данными, переписываются только настоящие вызовы |
| Сериализация снимка | Исправлен дефект: программы хранятся каноническим текстом; глубина AST не складывается с глубиной снимка |
| Критерий improve | Изменена постановка: после полного успеха допускается строгое Парето-улучшение действий/fuel/байтов |
| Свидетельство улучшения | Стоимость измеряется и подписывается evaluator; ReleaseDecision содержит пары затрат и результат доминирования |
| Демонстрация | Успешный агент действительно улучшается второй раз на всех 12 уровнях, затем проходит конденсация и retain |
| Спецификация | Добавлены условия использования абстракции, ТРИЗ, идеальности, операторного кредита, разнообразия и mG-Pass@k |
| Совместимость | Новый формат снимка и домен IDs 1.4; перенос старых полномочий и свидетельств не автоматический |

Сохранены абсолютный успех retain, наследование гарантий родителя,
раздельные ключи observer/evaluator, связь оценки с оплаченным
исполнением и проверка протокола до расходования свидетельств.

Добавлены 16 регрессионных тестов. Полный результат: см.
`reports/verification.json`. Подробности исправлений и пределы
утверждений: `AUDIT-CLOSURE.md`. Формальные правила: `SPEC.md`, §9,
§11–12 и §14–15; структурные схемы: `protocol-schemas.json`.

Проверено: **83/83 теста**, 6480 состояний K12, 2000 обращений API;
PEP 8 — без замечаний. Три выпуска в демонстрации, 72 учтённых эпизода.
