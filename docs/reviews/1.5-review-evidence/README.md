# AHSL 1.5: воспроизводимое ревью

Начните с `AHSL-1.5-execution-review.md`.

`inputs/` содержит неизменённые исходные архивы AHSL 1.5 и отдельного эксперимента 0.3. `observed-results/` содержит результаты выполненных проверок. `fix-recursion.patch` — отдельный проект исправления, а не замена подписанного или закреплённого релиза.

## Полный повтор

Требуются CPython 3.12.14, стандартная библиотека и утилита `patch`. Версия Python закреплена в плане эксперимента 0.3. Модельные API и ключи для этих проверок не нужны.

```bash
python reproduce.py --output /absolute/path/to/a-new-directory
```

Каталог должен быть новым. Скрипт распакует исходники, проверит манифест и штатные тесты, воспроизведёт ошибку, повторит сохранённые журналы 0.3, затем проверит патч в отдельной копии. Исходные архивы не изменяются.

## Только воспроизведение ошибки

Распакуйте `inputs/AHSL-1.5.zip` и укажите каталог, содержащий `ahsl/` и `manifest.json`:

```bash
python review_checks.py --source /path/to/ahsl-1.5 --output recursion.json
```

Этот скрипт ожидает поведение исходной версии: RecursionError при обычном стеке и успешное исполнение в диагностическом контроле. Для проверки исправленного поведения используйте новые тесты из патча.

## Применение проекта исправления

В отдельной копии AHSL 1.5:

```bash
patch -p1 --batch -i /absolute/path/to/fix-recursion.patch
python -m unittest discover -s tests -v
```

Ожидаемый результат — 102 прошедших теста. Старый source manifest после изменения исходников закономерно не совпадёт. Новый выпуск и его идентичность должны оформляться отдельно; комплект не пересобирает старый манифест для сокрытия изменений.

Сохранённые результаты относятся к программному имитатору, проверке кода и диагностическим контролям. Сравнение Ralph / Ralph с gate / декомпозиция с gate на реальной LLM не выполнялось.
