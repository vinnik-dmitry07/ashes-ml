# AHSL 0.6

Исполняемая спецификация харнеса с защищённой политикой, типизированными графами, локальными контрактами, версионированными навыками и отдельным протоколом допуска обновлений.

## Начать

Требуется Python 3.12; сторонние пакеты не нужны. Из каталога этого пакета:

```bash
python3 verify.py
```

Команда проверяет контрольные суммы, прежнее ядро, 37 тестов нового профиля и синтетический пример выпуска. Обновляет только отчёт проверки и производный пример. TLC, модели LLM, API и обучение не запускаются.

## Файлы

| Файл | Назначение |
|---|---|
| `SPEC.md` | Итоговая спецификация, включая формулы и границы гарантий |
| `RESEARCH.md` | Пять проходов исследования, первичные источники и принятые решения |
| `system.py` | Глобальный чистый переход `step(state, principal, event)` |
| `workflow.py`, `contracts.py` | Граф исполнения и язык предикатов |
| `artifacts.py`, `evidence.py` | Неизменяемые объекты и точная оценка обновления |
| `decisions.py` | Plurality, Borda и Pareto с определёнными крайними случаями |
| `examples/scenario.py` | Минимальная политика, конфигурация и синтетическая оценка |
| `examples/release.json` | Результат синтетического выпуска; не эмпирический результат LLM |
| `tests/test_profile.py` | Тесты контрпримеров и арифметики |
| `kernel/` | Сохранённый AHSL-Core 0.5 с его документами и проверками |
| `research/AHSL-0.5-before.md` | Предыдущая основная спецификация для сопоставления |
| `manifest.lock.json`, `verification.json` | Идентичность релиза и фактические результаты проверки |

## Минимальный интерфейс

```python
from examples.scenario import fixture, value
import system

policy, artifacts, configuration = fixture()
state = system.initial(policy, artifacts, configuration)
state, result, requests = system.step(state, 'agent', {
    'id': 'start1', 'kind': 'start_run',
    'run': 'run1', 'args': {'x': value(2)},
})
state, result, requests = system.step(state, 'agent', {
    'id': 'drive1', 'kind': 'drive', 'run': 'run1',
})
assert system.invariants(state)
```

`requests` — описание работы для адаптера. Этот код не исполняет полученный от модели Python, не создаёт sandbox и не обращается к провайдеру. Principal здесь задаёт доверенный тестовый код; production-адаптер должен определять его через аутентификацию.

## Гарантии

Это проверяемая операционная спецификация, а не формально доказанная промышленная система. Реальные полномочия, внешние эффекты, стоимость и независимая оценка требуют адаптера согласно §16 SPEC. Успех 64 тестов не равен доказательству для всех потоков событий.

Архив содержит прежнюю TLA+-абстракцию ядра. Новая глобальная модель в TLA+/Lean и доказательство её соответствия Python не созданы. Результаты прежнего Core не распространяются автоматически на расширение.
