# Изменения AHSL 1.5

11 сентября 2026. База — воспроизведённый AHSL 1.4. Его документация сохранена в `history/`.

| Изменение | Смысл |
| --- | --- |
| Поиск F2 | Forward получает тот же индекс подцелей и поддержку вложенных конъюнкций. Оба режима оплачивают построенные pair. Заявление об ускорении планирования снято. |
| Стоимость программы | `program_bytes` считается после нормализации связанных имён фиксированной ширины. Литералы остаются данными; общие узлы AST разворачиваются по вхождениям. |
| Критерий improve | Новый профиль `SUCCESS_THEN_PARETO_COST_2`. Действия, fuel, правило Парето, абсолютный успех и гарантии сохранены; изменилась байтовая ось. |
| Долговечное владение | D12 хранит checkpoint и revision в SQLite вне снимка, отзывает прежний экземпляр и помечает незавершённую операцию pending. |
| Восстановление | `DurableSession.restore/open` проверяют актуальную БД. Прежний `Session.restore` заменён явно ограниченным `restore_integrity` для офлайн-декодирования. |
| Фаззеры | Старые 2000 запросов получают точные счётчики границ и OK. Добавлены валидные жизненные циклы и мутации AST запросов, типов, подписей и fuel. |
| Полномочия | Добавлен прямой отрицательный тест одинаковых observer/evaluator; удаление guard должно ломать тест. |
| Реестр сервисов | Проверяется форма и сигнатура до исполнения. Некорректный реестр не вызывает callback. |
| Четыре плана | Сохранён и явно назван пожизненный предел; завершённые планы слот не возвращают. |
| Совместимость | Домен `AHSL/1.5/`, purpose `AHSL15-observer/evaluator`, version снимка 1.5. Старые свидетельства не мигрируют автоматически. |

Добавлены 15 адресных регрессионных тестов. Набор 1.4 сохранён с обновлённым именем офлайн-восстановления и ожидаемой новой метрикой; старый тест преимущества декомпозиции заменён равноправным контролем. `verify_mutations.py` проверяет, что удаление трёх защит вызывает именно поведенческий провал соответствующего теста, а не отказ манифеста.

D12 — локальный доверенный владелец на POSIX/SQLite, не независимый аппаратный счётчик. Откат его БД также откатывает внешний счётчик. При pending требуется отдельное административное восстановление; автоматический retry намеренно отсутствует. Эти границы входят в спецификацию.

Внешние отказы wire-квоты, размера и формы типа не создают новый checkpoint D12; лимиты проверяются до pending.

## Исправление рекурсии исполнителя

30 сентября 2026. Исправление из обзора исполнения 1.5; это не новый выпуск.

Исполнитель L12 больше не зависит от глубины стека Python: вычисление идёт явным стеком продолжений, порядок эффектов и учёт fuel сохранены. Пределы глубины 64 и fuel остаются в силе. В примере Mission в `SPEC.md` профиль исправлен на `SUCCESS_THEN_PARETO_COST_2`, как в коде. Добавлены четыре регрессионных теста границы рекурсии.
